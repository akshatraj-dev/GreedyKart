# RegretKart 💀💅✨

> **“You Didn't Need It. You Bought It Anyway.”**  
> *Ordinary Products. Absolutely Unnecessary Transformations.*

Welcome to **RegretKart**, a colorful, hyper-pop Gen-Z e-commerce web application that elevates mundane shopping into cinematic, hilarious main-character experiences. Every single product in the catalog pairs a **Real Studio Product Photograph** with a synchronized **4-Scene Interactive Character Animation Rig**.

---

## 🔥 Key Features

### 🎭 Main Character Energy™ Transformation Engine
Selecting any product opens an immersive 4-scene animated transformation modal:
1. **Scene 1: The Ordinary Beginning** – Clean product illustration and real studio photo floating on stage (*"AN ORDINARY PERSON HAS ENTERED THE CHAT."*).
2. **Scene 2: Precision Lock-In** – Animated vector rigs snap onto character anchors (sunglasses align to eyes, headphones clamp to ears, watches latch onto wrists, and T-shirts stitch mid-air).
3. **Scene 3: The Hero Reveal** – Neon speed lines, comic impact bursts, atmospheric mists, and punchy character headlines (*"BRO JUST UNLOCKED MAIN CHARACTER ENERGY."*).
4. **Scene 4: E-Commerce Control Panel** – Seamless checkout interface with real photo reference badges, live variant pickers, replay capabilities, and bag management.

### ⚡ Storefront & Account Features
* **Dual Display Cards**: Real studio photograph and live animated vector rig displayed side-by-side on every card with full-bleed view toggles (`Photo + Anim`, `Photo`, `Rig`).
* **Multi-Dimensional Sorting & Filtering**: Filter by price brackets, customer ratings (★ 4.8+), and catalog order (Price Low/High, Rating, Popularity, A–Z).
* **Account Dashboard & Delivery Tracking**:
  * 1-Click Demo Login and custom Gen-Z avatar selector (😎, 💅, 💀, 👑).
  * Real-time **4-Stage Order Tracker** (`Processing` → `Dispatched` → `Out for Delivery` → `Delivered`).
  * Itemized order history, reorder buttons, and personal stats (*Impulse Regret Spent*, *Main Character Aura Points*).
* **Accessibility**: Native keyboard controls, Escape key modal handling, memory leak cleanup, and a global **Reduced Motion** toggle.

* **Frontend**: React (TypeScript)

* **Animation**: Lightweight Custom React Hooks & CSS Keyframes/Transforms
* **Artwork**: Layered SVG Vector Rigs & Studio Photography References
* **Build Tool**: Vite
